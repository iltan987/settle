One source of truth. One BackupState drives the chip, the NoticeCards and this header. Priority when several apply: needs attention › signed out › Drive full › Drive not connected › location access › paused by you › backing up › all in Drive. Only the top state shows; the others appear as rows lower on the tab. The location state refers to Android's "access media location" permission; without it, uploaded originals would lose their GPS data, so Settle pauses instead of uploading stripped copies.
