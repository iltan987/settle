I Settings
Tapping the avatar opens Settings as a pushed screen with a back arrow, never a tab. Other parts: A–H Onboarding and folders · J Backup tab.
SettingsListGroups on bg. Each has a pri title (13.5/600) over a surf card (radius 20) with 1 dp dividers. A SettingsRow is at least 56 dp: 24 dp icon, title 15/500, sub 13/400, then one trailing control. Two-line subs wrap, never truncate.
Trailing controlsSwitch (52×32, pri when on with a check thumb), chevron for sub-pages, open_in_new for external links, a radio on the leading side for choices, and a button (40 dp, 48 dp touch) for one-shot actions. Any row whose action isn't currently needed is removed, not disabled.
ScannabilityEvery row's sub carries its current value, so the main page reads as a status summary. Problems use the warn or err icon tint plus words in the sub, never colour alone.
