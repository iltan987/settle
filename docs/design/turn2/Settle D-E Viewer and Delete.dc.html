E · Delete
E1First delete: explain Android’s confirmation (once)
delete
Delete with one tap
Android asks you to confirm each time Settle moves something to the trash. Allow Settle to manage media to skip that step. It’s optional, and deleted items can still be restored for 30 days.
Allow in Android settings Keep confirming each time
When. On the first delete only, before the system dialog, and only if "Media management" isn't granted. Either button continues the delete. "Allow" opens the system page. Whether it was granted or not, the delete then goes through (with the system dialog if needed). It never shows again. The choice lives in Settings → Deletion. MediaAccessSheet: modal sheet, 48 dp icon tile, full-width 48 dp buttons that wrap their text.

E5Deleting items that aren’t backed up
No extra confirmation. The items are still restorable for 30 days, so delete stays one tap and the snackbar says it plainly. It wraps to two lines, with Undo on the right and never truncated. If the selection holds only not-backed-up items: "Moved to the trash. These weren’t backed up; they’re deleted for good after 30 days." Trash marks these items with a cloud_off badge (F1).
